# Corrections and conventions

Places where a Lean statement differs from the book: a hypothesis made explicit, a claim
corrected, or a convention chosen.

## Corrections

| Where | Book | Lean |
| --- | --- | --- |
| §7.1, p. 170 | In any metric space the Borel sets are generated by the open balls. | This needs separability (`borel_eq_generateFrom_balls`, for a separable metric space). With the discrete metric on `ℝ` every set is a union of balls of radius `1/2`, so the Borel σ-algebra is the power set. The balls generate only the countable and co-countable sets (`discrete_balls_ne_top`). |
| Theorem 7.11, p. 194 | For σ-finite `λ ≪ μ` there is an *integrable* `h` with `λ(A) = ∫_A h dμ`. | The density is a finite-valued nonnegative measurable function, integrable exactly when `λ` is finite. With `λ = μ` Lebesgue measure on `ℝ`, every density has integral `+∞` (`theorem_7_11_not_integrable`). The book's uniqueness proof uses `∫_X g − ∫_X h = 0` and so needs `λ` finite (`theorem_7_11_unique_book`). The σ-finite case is `theorem_7_11_unique`. |

## Proofs that differ

| Where | Book | Lean |
| --- | --- | --- |
| Theorems 7.2, 7.2′, 7.3, pp. 175–177 | Proofs omitted ("available in any standard text"). | Theorem 7.2 is Mathlib's construction of a measure from a σ-subadditive additive content. The content is the book's measure on the algebra, and σ-subadditivity follows from countable additivity (`theorem_7_2`). Theorem 7.3 is uniqueness of measures agreeing on a generating π-system with a finite cover (`theorem_7_3`). For Theorem 7.2′ the completed measure is the outer measure on the null-measurable sets, and it is unique when `μ` is σ-finite (`theorem_7_2'`, `theorem_7_2'_unique`). |
| Theorem 7.6, p. 184 | Cited from Hildenbrand (1974). | Proved by lexicographic minimization (`theorem_7_6`). A compact-valued u.h.c. correspondence has closed lower inverses of closed sets (`isMeasCorr_of_uhc`). The least `i`-th coordinate is measurable, and the minimizers form another correspondence of the same kind (`IsMeasCorr.refine`). After `m` steps a single point remains, and its coordinates are measurable. |
| Theorem 7.13, p. 196 | Proves that the extension to finite unions is well defined, then "properties (a) and (b) ensure that `μ` is a measure". | Countable additivity on the algebra of finite unions is proved separately (`semiExtend_isAlgebraMeasure`). Each set in a disjoint representation of the union splits into the countably many rectangles `C ∩ D`, and the double sums are exchanged. The argument is for any semialgebra (`FiniteUnions`), so it also gives Exercises 7.6, 7.27 and 7.29. |
| Exercise 7.7a, p. 174 | Show that length is a measure on `𝒜`. | Countable additivity of length on `𝒜` is inherited from Mathlib's Lebesgue measure, whose construction proves it by compactness (`ex_7_7a`). Its uniqueness on the Borel sets follows from Theorems 7.2–7.3 (`length_unique`). |
| Theorem 7.10, p. 192 | Proof by Fatou's Lemma applied to `g ± fₙ`. | Mathlib's dominated convergence theorem (`theorem_7_10`). |
| Exercise 7.13b, p. 182 | Baire functions on `ℝˡ`. | On any metric space (`ex_7_13b`). The Baire functions are closed under continuous combinations `Φ(f, g)`. The sets with a Baire indicator form a σ-algebra containing the open sets, since `χ_U = lim min(1, n·dist(·, Uᶜ))`. Theorem 7.5 then finishes. |
| Exercise 7.30, p. 199 | Hint: a set in `ℝ²` that is `ℒ²`-measurable but has a non-`ℒ¹`-measurable section. | The set is `N × {0}`, with `N` the Vitali set constructed here (`vitaliSet_not_nullMeasurable`). It lies in the null set `ℝ × {0}`. |

The book's own proofs are followed for Theorem 7.1, Theorem 7.4, Theorem 7.5, Lemma 7.7, the Monotone Convergence Theorem 7.8 and Fatou's Lemma 7.9. They are also followed for Lemma 7.12, Theorem 7.14, the Monotone Class Lemma 7.15 and Theorem 7.16 (through the Radon–Nikodym Theorem). The Monotone Convergence Theorem uses the book's definition of the integral as a supremum over finite-valued simple functions. That definition is identified with Mathlib's `lintegral` without using the theorem itself (`bookIntegral_eq_lintegral`).

## Hypotheses made explicit

| Where | Book | Lean |
| --- | --- | --- |
| Measures on algebras, p. 174 | A real-valued function. | Values in `[0, +∞]`, as the book's own length example (Exercise 7.7) requires. |
| Exercise 7.9b, p. 178 | "Give an example where the reverse implication does not hold." | On `ℝ` with the countable and co-countable sets, every level set of the identity is measurable but `{x ≤ 0}` is not (`ex_7_9b_converse_fails`). |
| Exercise 7.12b, p. 182 | `inf fₙ`, `sup fₙ`, `lim inf fₙ`, `lim sup fₙ` for real `fₙ`. | They can take the values `±∞`, so they are taken in `[−∞, +∞]` (`ex_7_12b`). |
| Exercise 7.29, p. 197 | A product of `n` measurable spaces. | `n ≥ 1`: for `n = 0` the product is one point and `∅` is not a rectangle. |
| Definition (6), p. 205 | `E(f | 𝒜)` is `𝒜`-measurable and satisfies (6). | Also integrable, so that `∫_C E(f | 𝒜)` is defined (`IsCondExp`). |
| Theorem 7.16, p. 205 | `(Ω, ℱ, μ)` a probability space. | A finite measure space (`theorem_7_16`). |
| Exercise 7.32, p. 207 | Countable partition of a probability space. | Any countable index set (`ex_7_32a`, `ex_7_32b`). |
| Exercise 7.33, p. 207 | Continuous density on the unit square. | Any measurable density. The computation is done for any product of σ-finite spaces (`isCondExp_fst_iff`, `comp_fst_ae_eq_iff`), then specialized to the square (`ex_7_33a`, `ex_7_33b`). |

## Conventions

| Where | Book | Lean |
| --- | --- | --- |
| σ-algebras, measures | Families of sets and set functions. | `IsSigmaAlgebra`, `IsMeasure` and `IsAlgebraMeasure` are the book's definitions. They are identified with Mathlib's `MeasurableSpace` and `Measure` (`isSigmaAlgebra_iff`, `isMeasure_iff`), whose API is used for later results. |
| Measurable functions | `{f ≤ a}` measurable for every `a`. | Mathlib's `Measurable` for the Borel σ-algebra (`measurable_iff_book`). |
| Exercise 7.6, p. 174 | Complements and finite unions of `(−∞, b]`, `(a, b]`, `(a, +∞)`, `(−∞, +∞)`. | The half-open intervals with endpoints in `[−∞, +∞]` (`hoi`), and the algebra of their finite unions, shown to be the smallest algebra containing them (`ex_7_6a`). |
| Theorem 7.5, p. 180 | `φₙ = Σ (k − 1)2⁻ⁿ χ_{Aₖₙ}`, which is `0` where `f ≥ n`. | The dyadic approximation is `n` where `f ≥ n` (`dyadic`), as in the book's extended-real case. It also satisfies (5). For real `f` it is applied to `f⁺` and `f⁻`. |
| Integrable functions, p. 191 | `f⁺`, `f⁻` with finite integrals. | `IsBookIntegrable` is Mathlib's measurable and `Integrable` (`isBookIntegrable_iff`), with the same integral (`bookIntegralReal_eq`). |
| Exercise 7.16, p. 185 | Upper and lower Riemann integrals. | Darboux sums over partitions `0 = a₀ < ⋯ < aₙ = 1` (`lowerSum`, `upperSum`). |
| Theorem 7.6, p. 184 | `S ⊆ ℝˡ`, `T ⊆ ℝᵐ` Borel sets. | The domain is any metric space with its Borel sets (a Borel `S ⊆ ℝˡ` as a subspace). The values lie in `ℝᵐ`, and the selection lands in `T` whenever `Γ(x) ⊆ T` (`theorem_7_6_subtype`). |
| Exercise 7.3, p. 170 | `S ∈ 𝓑ˡ`. | Any measurable subset of a measurable space (`ex_7_3`). |
| Exercise 7.10b, p. 178 | A countable set with all subsets measurable. | Countability is not needed (`ex_7_10b`). |
| Chapter 3 results | Cited. | The Chapter 3 correspondences module (`IsUHC`) is carried over for Theorem 7.6. |
