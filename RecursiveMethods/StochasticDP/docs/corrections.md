# Corrections and conventions

Places where a Lean statement differs from the book: a claim corrected, a hypothesis made
explicit, or a convention chosen. Every correction marked *Lean* is backed by a proved
counterexample or a proof of the corrected statement.

## Claims corrected

| Where | Book | Lean |
| --- | --- | --- |
| Theorem 9.4, p. 251; Exercise 9.5b, p. 259 | An optimal plan `π*` agrees almost everywhere with a plan `π^G` *generated by `G`*, i.e. built from measurable selections `π^G_t = g_t(x_t, z_t)`. | False when `G` is not single-valued (*Lean*: `theorem_9_4_counterexample` — i.i.d. fair coins, `F ≡ 0`, `π*₂(z₁, z₂) = z₁`, which no `g₂(x₂, z₂)` copies). The proof breaks where it defines `π^g` by one selection `g`. What the argument shows, and what is proved, is that `π*_t ∈ G(x_t, z_t)` `μᵗ`-almost everywhere (`theorem_9_4`). This also needs `β > 0`: with `β = 0` only the first action matters. |
| Exercise 9.7d, p. 270; manual p. 156 | With `φ(·, ·, z′)` concave (and Assumptions 9.10–9.11), `v(·, z)` is strictly concave and `G` is a continuous function. | Two gaps. (1) `f[φ(x, y, z′), z′]` is concave in `(x, y)` only if `f` is also nondecreasing in `x`; the contraction must run on functions that are concave *and* nondecreasing, so the hypotheses of part (c) are needed (`ex_9_7d_concave`); with `φ(·, ·, z′)` affine no monotonicity is needed (`ex_9_7d`). (2) Single-valuedness of `G` does not follow from Assumption 9.10, which is strict only in `x`: if neither `F` nor `φ` depends on `y` (e.g. `F(x, y, z) = −x²`, `φ(x, y, z′) = x/2`, `Γ ≡ [0, 1]`), every feasible `y` is optimal. It holds when `φ(x, ·, z′)` is one-to-one (`ex_9_7d_policy`), as in the first formulation. |
| Exercise 9.7g, p. 270; manual p. 157 | Under Assumptions 9.13–9.15, `v(x, ·)` is strictly increasing. | In the second formulation the integrand `f[φ(x, y, z′), z′]` must be nondecreasing in `z′`. This needs `φ(x, y, ·)` nondecreasing (the manual adds this) and `f` nondecreasing in `x`, so the hypotheses of part (c) are added (`ex_9_7g`). In the first formulation no extra hypothesis is needed (`theorem_9_11`). |
| Exercise 9.9, p. 272; manual p. 159 | `M` preserves quasi-concavity in `x`. | False (*Lean*: `ex_9_9_quasiconcave_false`). With `Q(z, ·) = ½δ₀ + ½δ₁`, the quasi-concave, homogeneous `max(u, 2u)` and `max(−u, −2u)` (`u = x₁ − x₂`) average to `|x₁ − x₂|/2`. The manual's proof picks the worse of two points for one shock and uses it for all. `M` does preserve concavity (`ex_9_9_concave`). |
| Exercise 9.10b, p. 272 | "Under what conditions is `v(·, z)` strictly quasi-concave?" The manual answers: `F(·, ·, z)` strictly quasi-concave, using Exercise 9.9. | Since `M` does not preserve quasi-concavity, the answer is given through concavity: if `F(·, ·, z)` is concave on `A_z`, strictly for non-proportional `x, x′`, and `A_z` is convex, then `v(·, z)` is concave, and strictly so along non-proportional pairs (`ex_9_10b`). Homogeneous functions are linear along rays, so this is the strongest form available. |
| Exercise 9.13, (9), p. 278 | The functional equation has a solution `v₀ + v₁z + v₂x + v₃zx − v₄x²`. | No function of this form is a solution when `ρ > 0` (*Lean*: `ex_9_13_book_form`). The maximized right side has the `z²` coefficient `(βv₃ρ)²/(2(c + 2βv₄))`. The solution needs a `z²` term `v₅z²`, with `v₅ = (βρv₃)²/(2D(1 − βρ²)) > 0`, `D = c + 2βv₄` (`ex_9_13`). The solutions manual adds `v₅z²` but its formulas for `v₅` and `v₁` omit the terms `βv₅ρ²z²` and `2βv₅ρūz` coming from `E z′² = ρ²z² + 2ρūz + E u²`. The coefficients are proved correct in Lean (`quad_coeffs`, `quad_rhs_eq`). |
| Exercise 9.16, p. 286 | For `θ ∈ (0, 1)`, `x_t` is not a first-order Markov process. | Depends on `θ`. For `θ < 1/2` it is false (*Lean*: `ex_9_16_markov`): `x_{t+1} ∈ [0, θ]` when `z_t = 0` and `x_{t+1} ∈ [1 − θ, 1]` when `z_t = 1`, so `z_t = 1{x_{t+1} ≥ 1 − θ}` and `x` is Markov. For `θ = (√5 − 1)/2` it is true (*Lean*: `ex_9_16`): the shock histories `(1, 1, 0)` and `(0, 0, 1)` give the same `x₄ = 1 − θ` (as `θ² + θ = 1`) but different `x₃` and `z₃`. |

## Hypotheses made explicit

| Where | Book | Lean |
| --- | --- | --- |
| Integrals throughout §9.1 | `∫ F dμᵗ` for functions assumed integrable "where needed". | Bochner integrals with explicit integrability hypotheses: of the returns and of `v(s_t)` along feasible plans in Theorem 9.2 (`ex_9_4`), and of `z′ ↦ v[φ(x, y, z′), z′]` in (5′) for Theorem 9.4. |
| Assumption 9.2 | `F ≥ 0`, `F ≤ 0`, or the limit of `uₙ` exists in `[−∞, +∞]`. | The limit is a hypothesis where needed (`hconv`). For `F ≥ 0` the value is also defined in `[0, +∞]` without integrability (`planValuePos`, `lemma_9_3_nonneg`). |
| Exercise 9.2b, p. 253 | Theorem 9.4 holds for `F` bounded above or below and `β < 1`. | Proved for bounded `F` (`ex_9_2b_theorem_9_4`), where Assumption 9.3 holds with `L_t = sup |F|`. For one-sided bounds the continuation values can be `−∞` on null sets, which needs extended-real integrals. That case is not formalized. Theorem 9.2 and Lemma 9.3 are proved for one-sided bounds (`ex_9_2b_theorem_9_2`, `ex_9_2b_lemma_9_3`). |
| Exercise 9.2a, p. 253 | `F` bounded above or below makes `F` integrable. | A one-sided bound does not give integrability; the returns are assumed integrable, and the limit then exists (`ex_9_2a`). |
| Blackwell's example, pp. 253–254 | A Borel `E ⊆ [0, 1]²` whose projection is not Borel (Souslin). | The construction is not in Mathlib; the example is proved for every measurable `E` (`blackwell_example`), and `v*` is not measurable whenever `Proj_Z E` is not. |
| Assumption 9.5 and Lemma 9.5, pp. 260–262 | `Z` countable with all subsets measurable, or `Z ⊆ ℝᵏ` compact with `Q` Feller. | Assumption 9.5 is used in the form "`M` maps bounded continuous functions to continuous ones" (`PreservesBC`). Lemma 9.5 proves it for any discrete `Z` (countability is not needed: `lemma_9_5_discrete`) and for compact `Z` with `Q` Feller (`lemma_9_5_compact`). |
| Assumption 9.4, 9.16 | `X ⊆ ℝˡ`, `Y ⊆ ℝᵐ` convex Borel sets. | Metric spaces for Theorems 9.6–9.7 and 9.11 (the order on `X` or `Z` any partial order); convex subsets of `ℝˡ`, `ℝᵐ` from Theorem 9.8 on. |
| Exercises 9.6, 9.7a | `F : A → ℝ` and `φ : D × Z → X` continuous, hence measurable. | `F` and `φ` are total functions. `F` modified off the closed graph `A` is measurable and agrees with `F` on `A` (`ex_9_7a`). The total `φ` is assumed measurable. |
| Theorem 9.10, p. 266 | `g(x₀, z₀) ∈ int Γ(x₀, z₀)` gives `g(x₀, z₀) ∈ Γ(x, z₀)` for `x` near `x₀`. | Proved from lower hemicontinuity and convex values (Assumption 9.11), as in Chapter 4 (`eventually_mem_Γ`). |
| Exercise 9.16 | `Pr(x_{t+1} ∈ A \| x_t, x_{t−1})`, conditional on events of probability zero. | Stated as a factorization of the joint law of `(x_t, x_{t+1}, x_{t+2})` through a transition function `R(x_{t+1}, ·)` (`IsMarkovAt`), as in Chapter 8. |
| Ex 9.12, p. 277 | The shocks `u` have finite mean and variance. | Only a finite second moment is used (`ex_9_12`). |

## Conventions

| Where | Book | Lean |
| --- | --- | --- |
| The two formulations, pp. 241, 255 | Proved separately: the first formulation in the text, the second in the exercises. | The second formulation is the general one (`Model`); the first is `φ(x, y, z′) = y` (`Model.first`). Each result is proved once, and the first-formulation theorems are corollaries (`theorem_9_2` from `ex_9_4`; Theorems 9.6–9.11 from Exercises 9.7b–g). |
| Plans and histories | `π_t : Zᵗ → Y`, `zᵗ = (z₁, …, z_t)`. | `Plan Y Z := (t : ℕ) → (Fin t → Z) → Y`, with the histories of Chapter 8 (`hist Q t z₀`). |
| `u(π, s₀)` and `v*` | Values in `[−∞, +∞]`. | `EReal`: `planValue` is the limit of `uₙ` (`limUnder`), `vStar` the supremum over feasible plans. |
| Theorem 9.12, p. 274 | The sequence `π̂ᵏ` approximating `v*`. | Suprema are taken directly (`theorem_9_12`, `vHat`). |
| Global plans, p. 254 | A remark on why `v*` may fail to be measurable. | Not formalized (no claim); Blackwell's example is. |
| §9.5 | Stochastic Euler equations, derived informally (no numbered result). | Not formalized. |
