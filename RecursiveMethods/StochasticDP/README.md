# SLP Chapter 9: Stochastic Dynamic Programming, in Lean

This is the `RecursiveMethods/StochasticDP` proof project in
[LeanEconomics/DynamicProgramming](https://github.com/LeanEconomics/DynamicProgramming). It covers
Chapter 9 of Stokey and Lucas with Prescott, *Recursive Methods in Economic Dynamics* (1989). Run
the commands below from this directory. [Return to the library index](../../README.md).

Chapter 9 extends dynamic programming to problems with exogenous Markov shocks. Every numbered
result (Lemmas 9.1, 9.3, 9.5, 9.5′ and Theorems 9.2, 9.4, 9.6–9.14) and every exercise (9.1–9.17)
is formalised. The one exception is Exercise 9.2b's claim about Theorem 9.4, which is proved for
bounded returns but not for returns bounded on one side only. Each result is proved for the book's
second formulation (an action space `Y` and a law of motion `x′ = φ(x, y, z′)`). The first
formulation is the special case `φ(x, y, z′) = y`, so its theorems are corollaries. Seven claims
are corrected, four of them with Lean counterexamples; see [corrections](docs/corrections.md).
The library contains **316 theorems**.

* **The principle of optimality** (§9.1).
  * Plans on finite shock histories, their values in `[−∞, +∞]`, and the supremum function `v*`.
  * Theorem 9.2: a solution of the functional equation satisfying the limit condition is `v*`,
    and plans generated by the policy correspondence `G` are optimal.
  * Lemma 9.3, the recursion for the value of a plan and its continuations: by dominated
    convergence under Assumption 9.3, and by monotone convergence for nonnegative returns.
  * **Theorem 9.4, corrected.** An optimal plan need not agree almost everywhere with a plan
    generated by selections from `G` (a Lean counterexample with fair coins). What holds, and is
    proved, is that its actions lie in `G` almost surely; this needs `β > 0`.
  * Returns bounded on one side (Exercise 9.2), and Blackwell's example of a non-measurable `v*`.
* **Bounded returns** (§9.2).
  * Lemma 9.5 in both of the book's cases: discrete shocks, and compact shocks with a Feller
    transition. Also Lemma 9.5′.
  * Theorem 9.6 / Exercise 9.7b (the contraction and its policy correspondence). Exercise 9.6 /
    9.7a: Assumptions 9.1–9.3 hold, so the fixed point is `v*`.
  * Theorems 9.7–9.11 / Exercise 9.7c–g: monotonicity, concavity, convergence of the policy
    functions, differentiability, and monotonicity in the shock. Exercise 9.7d needs extra
    hypotheses (a nondecreasing value for a concave `φ`; a one-to-one `φ` for a single-valued
    `G`), and Exercise 9.7g needs a monotone `φ`.
* **Constant returns to scale** (§9.3).
  * The Banach space `H(S)`, and Exercises 9.8 and 9.10.
  * Exercise 9.9: `M` preserves concavity. **It does not preserve quasi-concavity** (a Lean
    counterexample).
* **Unbounded returns** (§9.4).
  * Theorem 9.12.
  * The log growth model (Exercise 9.11).
  * The linear-quadratic model with autoregressive shocks (Exercises 9.12–9.14). **The book's
    quadratic value function (9) solves nothing:** a `z²` term is needed, and its coefficient
    and the others are verified exactly.
* **Policy functions and transition functions** (§9.6).
  * Theorems 9.13–9.14 and Exercises 9.15 and 9.17.
  * Exercise 9.16. **The endogenous state is a Markov process for `θ < 1/2`**, contrary to the
    exercise. It is not Markov at `θ = (√5 − 1)/2`.

All names are in the namespace `StokeyLucasPrescott.StochasticDP`. See the
[source map](docs/source-map.md) and the [corrections](docs/corrections.md).

## Build and verify

```sh
lake exe cache get
python scripts/verify.py
```

The verifier builds the library and freshly recompiles every contributed proof. It also audits
each named declaration's axioms: only `propext`, `Classical.choice` and `Quot.sound` are allowed.
Warnings fail the check.
