# Corrections and conventions

Places where a Lean statement differs from Miao's Chapter 1 (draft of 21 April 2013): a claim
corrected, a hypothesis made explicit, or a convention chosen.

## Corrections

| Where | Book | Lean |
| --- | --- | --- |
| (1.5), p. 7 | For `|b| < 1` and bounded `{z_t}`, `lim x_t` exists ("a finite limit exists because we assume `{z_t}` is a bounded sequence"). | False: for `z_t = (−1)ᵗ` and `c ≠ 0` no solution converges, for every `b` (`eq_1_5_counterexample`). True: if `z_t → z̄` then `x_t → cz̄/(1 − b)` (`eq_1_5_tendsto`); bounded `z` gives bounded `x` (`eq_1_5_bdd`); and any two solutions approach each other, so the long run does not depend on `x₀` (`eq_1_5_sub_tendsto`). |
| p. 7 | If `|b| = 1` the solution does not converge unless `Σ z_j` is finite, and then the limit depends on `x₀`. | Right for `b = 1` (`eq_1_5_b_one_tendsto_iff`, `eq_1_5_b_one_limit_sub`). Wrong for `b = −1`: with `z ≡ 1`, `c = 1`, the solution `x ≡ 1/2` converges although `Σ z_j = ∞` (`eq_1_5_b_neg_one_counterexample`), and at most one `x₀` gives a convergent solution (`eq_1_5_b_neg_one_unique`). |
| p. 7 | If `|b| > 1`, "(1.4) shows that `{x_t}` diverges". | Not every solution diverges: the forward solution (1.8) is bounded, and every other solution has `|x_t| → ∞` (`eq_1_8_others_diverge`). |
| Case 1, p. 13 | If `|λ₁|, |λ₂| > 1` the solution "explodes". | Only in the sense of being unbounded: for roots `±2`, `2ᵗ + (−2)ᵗ` vanishes at every odd `t` (`case1_source_not_tendsto`). Every nonzero solution is unbounded (`case1_source`). |
| Case 2, p. 14 | The general solution is `(c₁ + tc₂)λ₁ᵗ`. | Only for `λ₁ ≠ 0` (`case2_general`); for `λ₁ = 0` the solution `0, 1, 0, 0, …` is not of that form (`case2_general_counterexample`). |
| §1.5, p. 28 | The phase diagram shows a convergent saddle path, and all other paths diverge. | The roots of `[[1 + a, b], [c, 1 − d]]` are real with `λ_lo < 1 < λ_hi`, but `λ_lo > −1` iff `(2 + a)(2 − d) > bc` (`phase_lamLo_iff`). Every `x₀` has a convergent path iff that holds (`phase_saddle_iff`); then the path is unique and lies on a downward-sloping line steeper than the `Δx = 0` isocline, and every other path is unbounded (`phase_saddle`, `phase_saddle_slope`). For `a = b = c = e = f = 1`, `d = 3` both roots are unstable and the steady state is the only bounded path (`phase_counterexample`). |
| (1.37), p. 26 | `u_t = −T₂₂⁻¹ Σⱼ (T₂₂⁻¹S₂₂)ʲ Q₂Cz_{t+j}`. | The forward solution of `S₂₂u_{t+1} = T₂₂u_t + Q₂Cz_t` is `u_t = −Σⱼ (T₂₂⁻¹S₂₂)ʲ T₂₂⁻¹Q₂Cz_{t+j}` (`eq_1_37`). The printed sum agrees only when `T₂₂⁻¹` commutes with `S₂₂`; for `S₂₂ = [[0, 1], [0, 0]]`, `T₂₂ = diag(1, 2)` it does not solve the system (`eq_1_37_printed_false`). |
| Ex 1(a), p. 41 | Conditions for a unique stable solution, for `ρ ∈ [0, 1]`. | For `ρ < 1`, `α > 0` suffices, for every `μ` and `m₀` (`ex_1_1a`). For `ρ = 1`, `μ ≠ 0`, money grows and no bounded solution exists (`ex_1_1a_rho_one_bdd_iff`); `p_t = m_t + αμ` is the unique solution with `p_t − m_t` bounded (`ex_1_1a_rho_one`). |
| Ex 2(b), p. 43 | Conditions for a unique stable solution. | In discrete time the saddle needs, beyond positive parameters, `θ(2δ + (2γ + δ)/β) < 4` (`ex_1_2b_iff`); with `δ = γ = β = θ = 1` only the steady state is bounded (`ex_1_2b_counterexample`). In (d) the adjustment is monotone only when the stable root is positive (`ex_1_2d_monotone`); otherwise it oscillates while converging. |
| p. 16 | If `det(Aα − B) = 0` for all `α`, (1.20) has no solution for generic `{z_t}`. | Not without more: for `A = B = diag(1, 0)`, `C = (1, 0)′` the pair is singular for every `α`, yet every `z` admits a solution (`remark_nonregular_counterexample`). If in addition `C` has a right inverse, some `z` that vanishes after a finite date admits no solution (`remark_nonregular_no_solution`); the book's `ψ` is a left null vector of `XA − B` over `ℝ[X]`. |
| (1.34), p. 23 | The initial values satisfying (1.34) form an `n_k`-dimensional subspace. | A linear subspace of dimension `n_k` without forcing (`stableArm`, `finrank_stableArm`). With forcing it is the affine translate `x̂ + stableArm`, `x̂ = (0, P_uy⁻¹u₀)`, a subspace only when `u₀ = 0` (`stable_initial_translate`). |
| Theorem 1.4.3, p. 23 | If `n_u > n_y` there is no solution to (1.22); if `n_u < n_y` there are infinitely many. | With `A` nonsingular a solution exists for every `x₀` (`exists_unique_solution`), so the first claim is false (`theorem_1_4_3_printed_gt_false`), and the second holds whenever `n_y ≥ 1`, whatever `n_u` (`theorem_1_4_3_printed_lt`). About stable solutions: if `n_u > n_y`, for every `z` some `k₀` has no stable solution (`theorem_1_4_3_gt`). If `n_u < n_y`, one stable solution gives infinitely many (`theorem_1_4_3_lt`), but there may be none: `W = diag(2, ½, ½)`, `n_k = 1`, `n_y = 2`, `k₀ = 1` (`theorem_1_4_3_lt_counterexample`); if `P_uy` has full row rank they exist for every `k₀` and stable `z` (`theorem_1_4_3_lt_exists`). |
| p. 23 | With unit-circle eigenvalues the constructed solution "may not be stable". | Example: `x_{t+1} = x_t + 1` satisfies (i)–(ii), has eigenvalue `1`, and no solution is stable (`remark_unit_root`). |

## Conventions and departures

| Where | Book | Lean |
| --- | --- | --- |
| Definition 1.4.2, p. 17 | `‖x_t‖_max < M`. | `IsStableSeq` uses the norm of the space; on `ι → ℝ` and `ι → ℂ` that is the max norm. |
| Example 1.1.1, p. 9 | The backward solution with `a = R(1 − λ)/(R − λ)`; "we must assume `|a| < 1`". | The printed formula is right, for `R ≠ λ`, `R ≠ 1`, `λ ≠ 0` (`example_1_1_1_backward`). Prices converge iff `p₀ = p̄` or `|a| < 1` (`example_1_1_1_tendsto_iff`); with `λ ∈ (0, 1)` and `R > λ`, `|a| < 1` iff `R > 1`, so the assumption holds for any gross return above one (`example_1_1_1_abs_a_lt_one_iff`). |
| Example 1.1.2, p. 10 | The timing of the tax change. | `p_t = (p_{t+1} + (1 − τ_{t+1})d)/R`: dividends paid at `s ≤ T` are taxed at `τ₁`, later ones at `τ₂`. This reproduces both printed formulas. "Drops at time 0" is read as: below the old fundamental value (`example_1_1_2_drop`). The decline is strict on `[0, T]` for `d > 0`, `τ₂ > τ₁`, `R > 1` (`example_1_1_2_decreasing`). |
| §1.2, p. 11 | Lag operators on `{X_t}_{t=−∞}^{∞}`. | Two-sided sequences `ℤ → ℝ`, any integer `n`; the expansions are the unique bounded solutions (`lag_inverse_geom`, `lag_inverse_geom_sq`). |
| Case 3, p. 15 | Real solutions `rᵗ(A cos θt + B sin θt)`, damped for `r < 1`, explosive for `r > 1`. | The general real solution needs `sin θ ≠ 0` and `r ≠ 0` (`case3_general`); "explosive" is proved as: every nonzero solution is unbounded (`case3_explosive`). |
| (1.42), p. 29 | First-order Taylor approximation. | For Example 1.6.1, the six partial derivatives at the steady state (`example_1_6_1_linearization`); the printed matrices, trace and determinant are all right. |
| Theorem 1.4.4, p. 25 | Item 5: the pairs `(s_ii, t_ii)` can be arranged in any order. | Proved for any scale-invariant predicate on the pairs: the pairs satisfying it come first (`theorem_1_4_4`); in particular the stable pairs first (`theorem_1_4_4_stable`), which is what Theorem 1.4.5 uses. Arbitrary permutations of the diagonal are not formalised. |
| Theorem 1.4.5, p. 25 | Conditions on `Z₁₁` and `n_s`. | Stated for a given QZ form with the stable pairs first, since `Z₁₁` and `n_s` depend on the decomposition; Theorem 1.4.4 supplies one. Condition (iii) is on `λ(A, B)`, as in the book; the diagonal form `‖t_ii‖ ≠ ‖s_ii‖` follows (`diag_off_circle`). The coordinates are `Fin (n_k + n_y)`, with `k` the first `n_k`. |
| p. 27 | A corollary similar to Corollary 1.4.1. | Slightly stronger: every stable solution converges to `x̄ = (A − B)⁻¹Cz̄`, without the condition on `Z₁₁` (`corollary_1_4_1_singular`). |
| Definition 1.4.1, p. 16 | A steady state of a sequence. | A point the sequence never visits is vacuously a steady state (`isSteadyStateOf_of_not_mem_range`), so the unique steady state of (1.21) is stated through the stationary equation (`eq_1_21`); that the solution stays at `x̄` is proved for nonsingular `A`, from date `T` on (`eq_1_21_steadyState`). |
| Theorem 1.4.2, pp. 17–20 | The complex Jordan form `W = P⁻¹JP`. | A real invertible `P` with `PWP⁻¹ = diag(J_s, J_u)`, `J_s` stable and `J_u⁻¹` stable (`IsRealBlockSplit`); one exists whenever no eigenvalue lies on the unit circle, with `n_s` the number of stable roots counted with multiplicity (`exists_real_block_split`). Condition (i) is carried but follows from (ii) with a two-sided inverse; existence needs only a right inverse of `P_uy` (`bk_exists`), uniqueness only a left inverse (`bk_unique`). The printed (1.29) and (1.33) are right. |
| §1.2, p. 12 | `(I − ALⁿ)⁻¹ = Σ AʲL^{nj}`, `n` any integer. | Proved for every `n ∈ ℤ` on two-sided bounded sequences (`lag_matrix_formula`). |
