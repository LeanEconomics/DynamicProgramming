# Source map: Miao Chapter 7

Jianjun Miao, *Economic Dynamics in Discrete Time* (draft of 21 April 2013), Chapter 7,
Infinite-Horizon Dynamic Programming, pp. 193–230. Lean names are relative to
`Miao.InfiniteHorizonDP` (the copied SLP deterministic machinery of §7.1 is in
`Miao.InfiniteHorizonDP.IHDet`). The setting is Chapter 5's Markov decision model (`MDP`,
`Plan`, `mu`, `J`, `V`, `feasiblePlans`) and Chapter 6's optimal control model (`OCModel`),
the latter viewed as a stationary Markov decision process in §7.3 (`br_ctrlMDP`); §7.5 uses
the Euler class `eu_EulerModel` with `X ⊆ ℝⁿ` as `Fin n → ℝ`. Departures from the book are
in [corrections](corrections.md).
