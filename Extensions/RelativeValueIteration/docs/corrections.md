# Departures from the sources

Places where a Lean statement differs from the published one: a hypothesis made explicit, a
special case proved, or a definition chosen among equivalent ones.

| Where | Published | How it is stated |
| --- | --- | --- |
| Convergence rates (Bray, 2019a, Prop 3; 2019b, Prop 4) | Asymptotic: the relative (endogenous) value error is `O⁺(βⁿλⁿ)` with `λ` the spectral subradius of `F(p*)` (of `ΛF(p*)`). | Two forms. Non-asymptotic: if `α` bounds the Dobrushin coefficient over all feasible state–action pairs (`α_y` the coefficient of the endogenous transitions within each exogenous state), the error in span is at most `(βα)ⁿ` (`(βα_y)ⁿ`) times the initial one, at every `n` (`sp_iterate_sub_vstar`, `spy_T_iterate_sub_le`). Asymptotic: for every `γ > λ` there are `C` and `N` with error at most `C(βγ)ᵏ` after step `N + k` (`relative_asymptotic_rate`, `endo_asymptotic_rate`). This is Bray's `O⁺(βⁿλⁿ)`, which by definition means `O((βλ + ε)ⁿ)` for every `ε > 0`. |
| Subradius | The largest modulus of an eigenvalue of `F` other than `1`; defined for irreducible chains. | `λ(Q) = ρ(ΔQ)` with `Δ = I − ι e_{s₀}′` (`subradius`), defined for every stochastic matrix. It equals the largest modulus of an eigenvalue other than `1` when the only fixed vectors of `Q` are constants (`spectralRadius_deltaQ`); otherwise `1` is an eigenvalue of `ΔQ` (`mem_spectrum_deltaQ_iff`) and `λ(Q) = 1`, which is the right rate: the span need not contract. |
| Asymptotic rates (Bray, 2019a, Prop 3; 2019b, Prop 4) | Each value function has a unique optimal policy (a notational assumption); the proof uses the envelope theorem to control the policy's changes along the iteration. | The optimal decision rule at `v*` is unique: at every state every other feasible action is strictly worse at `v*` (with finitely many actions, uniqueness and strictness coincide). The greedy policy then freezes after finitely many steps (`eventually_T_eq_Tσ`), after which value iteration is policy evaluation of `σ*` (`eventually_linear`); no envelope-theorem argument is needed. |
| Matrix norms (Bray, 2019b, Prop 5) | `max_x ‖ΩF_y(p, x)‖` for a matrix norm with a compatible vector norm. | A vector norm `N` on `ℂ^Y` (`IsVecNorm`) and a bound `c` with `N(ΩF_y(σ, x)u) ≤ c·N(u)` for all `u` and `x`. A compatible matrix norm dominates the induced operator norm, so this hypothesis is weaker than Bray's. |
| Singular values and the Frobenius norm (Bray, 2019b, Cor 2(a), (b)) | The largest singular value of `ΩF_y(p, x)`; the Euclidean norm of `vec(ΩF_y(p, x))`. | `(Matrix.toEuclideanLin M).singularValues 0` (Mathlib's `LinearMap.singularValues`) of the real matrix `M = ΩF_y(σ, x)`; `√(∑_{y,y'} M_{yy'}²)`. Both bound the `ℓ²` operator norm on real vectors, which is extended to complex vectors through real and imaginary parts (`sum_sq_norm_cmulVec_le`). |
| Non-ergodicity (Bray, 2019b, Cor 3) | `F_x` is not ergodic, so `σ(F_x) = 1`. | `F_x` has a non-constant fixed vector or an eigenvalue `μ ≠ 1` with `|μ| = 1`; this gives `σ(F_x) ≥ 1` (`one_le_subradius_of_nonergodic`), which is all the argument needs. Scrambling: any two rows of each `F_y(σ, x)` share a state with positive probability. |
| `ρ(ΛF) ≤ λ(F)` (Bray, 2019b, Prop 4) | For transition matrices of the form `F_x ⊗ F_y`. | For any stochastic `F` mapping functions of `x` to functions of `x` (`PreservesLift`), which every policy matrix of an `ExoMDP` does (`Pmat_preservesLift`). |
| Relative value iteration | Subtract `v(x₁)`. | Subtract `v(s₀)` for any reference state `s₀`. |
| Endogenous value iteration | `Λ = I_X ⊗ (I_Y − ιι′/Y)`. | `Λv(x, y) = v(x, y) − mean_{y'} v(x, y')` (`endo`); the action space may depend on the state. |
| Stopping rule (Bray, 2019a) | Stop when `‖V_n − V_{n−1}‖ < ε(1 − β)/(2β)`; return the policy greedy for `V_n`. | The policy greedy for `V_n` is `ε`-optimal once `|V_{n+1} − V_n| ≤ ε(1 − β)/(2β)` (`stopping_rule_sup`), via the sharper span criterion `β/(1 − β)·sp(V_{n+1} − V_n) ≤ ε` (`stopping_rule`). |
| Endogenous `ε`-optimality (Bray, 2019b, Prop 3) | Stopping rule on endogenous iterates. | An a priori bound: the policy greedy for `ΛTⁿV₀` is within `2β/(1 − β)·spy(TⁿV₀ − v*)` of optimal (`endo_policy_error`), combined with `spy(TⁿV₀ − v*) ≤ (βα_y)ⁿ spy(V₀ − v*)`. |
| Policy iteration (Bray, 2019a, §4.1; 2019b, §5) | `U_n := U(V_{n−1})` with the greedy policy assumed unique; `V_0 := 0`. | Any sequence of policies with `σ_{n+1}` greedy for `Δv_{σ_n}` (`Λv_{σ_n}`) and `σ_0` feasible; ties may be broken arbitrarily. |
| Relative policy iteration's stopping rule (Bray, 2019a, Prop 4) | Proved as a special case of Bray (2018). | Proved directly: after an improvement step the Bellman residual of `v_{σ'}` lies in `[0, β·sp(v_{σ'} − v_σ)]` (`pi_residual_le`), and the proof bounds the returned policy's error by `βε ≤ ε`. |
| Endogenous policy iteration's stopping rule (Bray, 2019b, Prop 3) | The stopping conditions hold after finitely many iterations. | Also that the returned policy is then `ε`-optimal, through the sharper error bound `β/(1 − β)·sp(Λ(Tw − w))` (`policy_error_endo`): adding to `w` the function of `x` that solves `c = mean_y(Tw − w) + βF_x c` leaves greedy policies unchanged and turns the residual into `Λ(Tw − w)`. |
| Average reward (White, 1963) | Unichain, aperiodic. | The Dobrushin coefficient over all feasible state–action pairs is below `1`, which implies both. |
